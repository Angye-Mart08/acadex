# GESTIÓN DE TUTORÍAS Y MONITORÍAS

Contrato de API para la versión web del sistema de acompañamiento académico de Unitrópico.

La especificación oficial está en [api/openapi.yaml](api/openapi.yaml) y sigue OpenAPI 3.1.0.
La arquitectura definida es React + TypeScript → API REST Node.js + TypeScript → MariaDB.

Para consultar la guía de integración, ejemplos HTTP y mock local, ver [api/api.md](api/api.md).
